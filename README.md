# age-credentials

> Identity & credential management built on the [age](https://age-encryption.org) encryption ecosystem.
> Currently in **active development** – not yet ready for production use.

## Goals

- A Rust library that brings GnuPG‑like identity management (user ID, keyring, passphrase protection) to the simplicity of age.
- Built on [`librage`](https://github.com/mroczect/librage), a safe Rust wrapper around the `rage` implementation.
- Designed for developers who want **programmatic control** over identities, not just a CLI tool.
